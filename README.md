# DDD (Domain Driven Design)

Design dirigido à domínio

## Domínio

- Domain experts
  - Pessoas que entendem profundamente o problema que estamos resolvendo com
  o nosso software.
  - Conversa.
- Linguagem ubíqua

- Usuário
  - Cliente
  - Fornecedor
  - Atendente
  - Barman

- Agregados
- Value Objects
- Eventos de domínio
- Subdomínios (Bounded Contexts)
- Entidades
- Casos de uso
