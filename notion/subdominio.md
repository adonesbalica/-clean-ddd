# Subdomínios

- Core: O que dá dinheiro, o que não pode parar.
- Supporting: Dá suporte para o core funcionar.
- Generic: Você precisa deles, mas não são tão importantes.

## Exemplos

### Core

- Compra
- Catálogo
- Pagamento
- Entrega
- Faturamento

### Supporting

- Estoque

### Generic

- Notificação ao cliente
- Promoções
- Chat
